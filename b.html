    #Rok Docs

    The guide, examples, language reference and standard library of Rok, for the version in the menu above.
    curl -fsSL https://rok-lang.org/install.sh | sh

    macOS and Linux. On Windows, use install.ps1.

    Guide
    Twenty chapters, from installation to concurrency, FFI, stones, and a cookbook. Every code sample is checked when the site is built.
    Examples
    Small complete programs: CLI tools, file processing, a TCP echo server, parallel map, an interpreter, and more.
    Language spec
    Ten chapters, from lexical structure through types, expressions, modules, the meta system, the runtime, and the ABI.
    Std library
    Every module, type and function of the standard library, generated from its sources.
    Library spec
    The specification of the three tiers bare / core / std.
    Error codes
    One page per rokc error code, with an example of the error and its fix.
    Tools
    The rokc compiler, the rok package tool, the REPL, the Jupyter kernel, the LSP server, and debugging tools.

    #Versions

    Each release has its own docs: docs.rok-lang.org/0.1/ for Rok 0.1.x, and so on; latest/ is the newest release and dev/ follows the main branch. The spec introduction gives the motivation and philosophy of the language. Packages (stones) are on rokstones.io.
