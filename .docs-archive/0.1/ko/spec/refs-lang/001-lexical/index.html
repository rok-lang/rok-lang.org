      #1. 어휘 구조

      이 장은 rok 소스 코드를 토큰으로 분해하는 규칙을 다룹니다. 구체적으로는 파일과 줄을 시작으로 식별자, 키워드, 리터럴, 그리고 연산자 토큰까지 토큰화 단계에서 마주치는 모든 요소를 살펴봅니다.

      타입과 표현식, 문장과 같은 상위 레이어는 이미 토큰화가 끝난 입력을 받아서 처리하기 때문에, 토큰화 단계에서 적용되는 규칙은 모두 이 장 한 곳에 모여 있습니다.
