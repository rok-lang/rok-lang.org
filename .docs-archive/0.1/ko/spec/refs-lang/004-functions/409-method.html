      #4.9. 메서드

      이 문서에서는 impl 안에서 정의되는 메서드의 매개변수와 호출 규약을 자세히 정의합니다. 본 문서는 함수 사양의 일부이며, 메서드와 자유 함수의 차이를 중심으로 다룹니다.

      #4.9.1. 메서드의 정의 위치

      메서드는 impl 의 블록 안에 정의됩니다.

      impl Point {
    fn origin() -> Point { Point { x: 0.0f64, y: 0.0f64 } }
    fn distance(self, other: Point) -> f64 { ... }
    fn translate(ref self, dx: f64, dy: f64) {
        self.x = self.x + dx;
        self.y = self.y + dy;
    }
}

      #4.9.2. 첫 매개변수의 형태에 따른 메서드 종류

      #정적 메서드: self 없음

      impl Point {
    fn origin() -> Point { ... }              // 정적
    fn from_polar(r: f64, theta: f64) -> Point { ... }
}

let p = Point::origin();                       // Type::method() 호출
let q = Point::from_polar(1.0f64, 0.0f64);

      정적 메서드는 첫 매개변수가 self 도 ref self 도 아닌 함수입니다. 호출은 Type::method(args) 의 형태로 이루어지며, 이는 타입 경로 의 정적 항목 접근에 해당합니다.

      #인스턴스 메서드: self

      impl Point {
    fn distance(self, other: Point) -> f64 { ... }
    fn norm(self) -> f64 { ... }
}

let d = p.distance(q);                         // instance.method() 호출
let n = p.norm();

      이 형태의 메서드는 첫 매개변수가 self 입니다. 여기서 self 는 그 인스턴스의 값 (struct 이면 사본, 2.3.8) 이며, 본체에서는 self.field 로 필드에 접근할 수 있습니다. 호출은 instance.method(args) 의 형태로 합니다.

      #인스턴스 메서드: ref self

      impl Point {
    fn translate(ref self, dx: f64, dy: f64) {
        self.x = self.x + dx;
        self.y = self.y + dy;
    }

    fn replace_with(ref self, other: Point) {
        self = other;                          // 호출자의 변수가 other 가 됨
    }
}

let p = Point { x: 1.0, y: 2.0 };
p.translate(5.0f64, 0.0f64);                   // ref 명시 없이 호출
p.replace_with(other);                         // 마찬가지

      이 형태의 메서드는 첫 매개변수가 ref self 입니다. 본체 안에서는 self 와 그 필드에 대입할 수 있고, 그 결과는 호출자의 변수에 되써집니다 (ref 키워드 참조). 호출자는 ref 를 명시하지 않는데, 이는 메서드 호출 receiver 가 자동으로 처리되기 때문입니다.

      #4.9.3. self 키워드의 두 사용

      impl Point {
    fn distance(self, other: Point) -> f64 {
        let dx = self.x - other.x;             // 인스턴스 self 사용
        let dy = self.y - other.y;
        (dx * dx + dy * dy).sqrt()
    }
}

      self (키워드) 는 두 가지 자리에서 사용됩니다. 매개변수 위치에서는 인스턴스 자신을 받는 매개변수의 역할을 하고, 본체 안에서는 그 매개변수를 가리키는 식별자로 쓰입니다.

      매개변수 자리의 self 는 타입을 명시하지 않고 적습니다. 타입은 자동으로 Self 즉 현재 impl 의 대상 타입이 됩니다.

      #4.9.4. Self 키워드: 타입 자리

      Self (키워드, 대문자) 는 현재 impl 의 대상 타입을 가리키는 타입 이름입니다.

      impl Point {
    fn new(x: f64, y: f64) -> Self {           // Self == Point
        Self { x, y }                          // Self 로 인스턴스 생성도 가능
    }
}

      두 사용을 명확히 구분해야 합니다. 소문자 self 는 매개변수와 인스턴스 식별자로 쓰이고, 대문자 Self 는 타입 이름으로 쓰입니다.

      #4.9.5. 메서드 호출 receiver 의 자동 ref

      ref self 메서드는 호출자가 호출 시점에 ref 를 명시하지 않아도 자동으로 ref 처리됩니다.

      impl Counter {
    fn increment(ref self) { self.count = self.count + 1; }
}

let c = Counter { count: 0 };
c.increment();                                 // 'ref' 명시 없음

      이는 ref 키워드 의 일반 함수 호출 규칙 (ref 명시 필수) 과 다른 예외에 해당합니다. 그 이유는 다음과 같습니다. 메서드 호출 문법인 x.method() 자체가 receiver dispatch 의 메커니즘이며, receiver 가 self 든 ref self 든 호출 형태가 동일하기 때문입니다. 또한 추가로 ref 를 명시하면 시각적인 잡음이 됩니다.

      이러한 처리는 Rust, C#, Swift 의 메서드 호출 관례와 일관됩니다. 다만 같은 메서드를 경로로 부를 때는 receiver 가 일반 인자이므로 ref 를 적습니다 (Counter::increment(ref c), 4.7.3).

      #4.9.6. 자유 함수와 메서드의 호출 형태

      형태호출
      자유 함수function_name(args)
      정적 메서드Type::method(args)
      인스턴스 메서드instance.method(args)

      같은 함수가 어떤 의미를 갖는지는 호출 형태로 명확히 구분됩니다.

      #트레잇 사이의 이름 충돌

      x.method() 의 후보가 여러 개일 때는 다음 순서로 고릅니다.

      1. 고유 impl 의 메서드가 트레잇 메서드보다 우선합니다.
      2. 트레잇 메서드끼리는, 현재 패키지가 정의했거나 명시적으로 use 한 트레잇이 암묵 use rok::core::** 로만 보이는 트레잇보다 우선합니다. 현재 패키지는 호출이 쓰인 실제 패키지입니다. 의존 패키지의 트레잇은 use 하지 않는 한 core 의 트레잇보다 우선하지 않습니다.
      3. 그래도 후보가 둘 이상이면 모호성 에러이며, 진단은 Trait::method(x) 형태로 적으라고 안내합니다. 
      use pkg::geom::Union;              // 사용자 트레잇 - union 메서드
a.union(b);                        // pkg::geom::Union 이 core 의 Union 보다 우선
rok::core::ops::Union::union(a, b) // core 쪽을 쓰려면 명시

      #4.9.7. 메서드 안의 다른 메서드 호출

      impl Point {
    fn distance(self, other: Point) -> f64 { ... }

    fn distance_squared(self, other: Point) -> f64 {
        let d = self.distance(other);          // 같은 인스턴스의 다른 메서드
        d * d
    }
}

      self.method() 형태로 같은 인스턴스의 다른 메서드를 호출할 수 있습니다. 일반 인스턴스 호출과 같은 규칙을 따릅니다.

      #4.9.8. 메서드 가시성

      메서드 가시성은 impl 에서 정의된 모듈 비공개 기본을 따릅니다.

      impl Account {
    pub fn balance(self) -> f64 { ... }        // 외부 공개
        fn _internal(self) { ... }              // 모듈 비공개
}

      가시성 단계의 정확한 규칙은 가시성 에서 정의합니다.

      #4.9.9. 메서드 시그니처의 자유도

      메서드의 매개변수, 반환, 본체는 모두 매개변수 와 반환 의 일반 함수 규칙을 그대로 따릅니다. 구체적으로, 기본값과 named 인자, variadic, spread 는 메서드에서도 자유롭게 쓸 수 있습니다. 본체가 throw 나 무한 루프로 항상 빠져나가는 형태인 divergent 메서드도 가능하며, 제네릭 메서드의 경우에는 impl 블록의 제네릭 매개변수와 메서드 자체의 제네릭이 함께 쓰일 수 있습니다.

      impl<T> List<T> {
    fn map<U>(self, f: fn(T) -> U) -> List<U> { ... }
}

      메서드 자체의 제네릭은 함수 이름 뒤에 둡니다 (fn map<U>(...)). 트레잇 impl 에서 타입이 없는 메서드 매개변수는 암묵 타입 매개변수가 아니라, 트레잇이 그 자리에 선언한 타입 (트레잇 매개변수와 연관 타입을 대입한 것) 을 가집니다.

      #4.9.10. 메서드 안의 self 관계 요약

      첫 매개변수의미호출 시본체에서 self 재할당 가능?
      (없음)정적 메서드Type::method()-
      self인스턴스 메서드 (값)instance.method()안 됨 (로컬만)
      ref self인스턴스 메서드 (ref)instance.method() (ref 자동)됨 (호출자에 반영)

      메서드의 종류는 이 세 형태가 전부입니다.
