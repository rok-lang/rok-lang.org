      #0. 표준 라이브러리 메타

      이 장은 표준 라이브러리 사양 전반에 걸쳐 적용되는 정책과 표를 한 자리에 모읍니다.

      #목차

      • 0.1. 3-tier 모델 (bare / core / std)
      • 0.2. import 정책 (use rok::core::**; - 자동 prelude 없음)
      • 0.3. intrinsic 메커니즘 - 컴파일러 ↔ 표준 라이브러리 경계
      • 0.4. #[lang] 슬롯 매핑 표
      • 0.5. 표기법

      #이 장의 역할

      이 장은 개별 트레잇이나 타입의 정의를 직접 다루지 않습니다. 그 대신, 라이브러리 전체 가 일관되게 따라야 할 규칙과 정책을 한데 정리합니다.

      먼저 3-tier 모델 은 의존성 방향을 규정합니다. std 는 core 와 bare 를, core 는 bare 를 사용할 수 있으나, 그 반대 방향의 의존은 허용되지 않습니다. import 정책 은 use rok::core::**; 가 묵시적으로 자동 적용되는 방식을 정합니다. 별도의 prelude 모듈을 두지 않으며, rok::core 위의 재귀 glob 이 그 역할을 직접 수행합니다. 이어지는 intrinsic 항목은 표준 라이브러리 메서드가 어떻게 컴파일러 백엔드 (PrimOp 등) 에 연결되는지를 다루고, 마지막으로 lang slot 은 #[lang(...)] 어트리뷰트를 통해 컴파일러가 lookup 하는 48 개의 슬롯이 표준 라이브러리 항목과 어떻게 매핑되는지를 보여줍니다.

      이러한 정책들이 먼저 정의되어야 비로소 200-core/ 의 트레잇 정의로 나아갈 수 있습니다.
