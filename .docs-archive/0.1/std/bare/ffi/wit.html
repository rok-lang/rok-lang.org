      rok::bare::ffi::wit

      rok::bare::ffi::wit - what the generated WIT bindings run on (stdlib 1.8): linear-memory access at canonical ABI addresses (i32), the blocks strings and lists lower into, resource handles and error-context. The async ABI is rok::std::wit (bare does not depend on core, 0.1.2). Blocks come from the C allocator, including the ones the host fills through cabi_realloc; a lifted string or list frees its block once copied into GC memory.

      Handle

      pub struct Handle

      The handle of an imported resource, shared by every copy of its value: passing an own on or dropping it empties them all.

      • pub const fn own(h: i32) -> Handle
      • pub const fn borrowed(h: i32) -> Handle
      • pub const fn get(self) -> i32
      • pub const fn take(self) -> i32

        The handle, given away (an own parameter).

      • pub const fn release(self) -> i32 | none

        The handle to drop, if this value still owns one.

      Table

      pub struct Table<T>

      The values of an exported resource, by representation (rep): a handle the host holds keeps its value alive here until the host drops it ([dtor]).

      • pub unsafe fn new() -> Table<T>

        The caller guarantees one thread at a time uses the table (the bindings make one per component instance).

      • pub fn insert(self, v: T) -> i32
      • pub fn get(self, rep: i32) -> T
      • pub fn take(self, rep: i32) -> T?

        The value of rep, its slot freed; none if it was taken already (a [dtor] after the value came back through an owned handle).

      Trait implementations 1
      • unsafe impl<T> Sync for Table<T>
