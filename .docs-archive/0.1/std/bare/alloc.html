      rok::bare::alloc

      rok::bare::alloc - raw allocation outside the GC (stdlib spec 1.4). Over the runtime's rok_alloc_raw / rok_realloc_raw / rok_free (system malloc); failure is a null CPtr, never an abort.

      Allocation<T> frees its block when its using block ends.

      Allocation

      pub struct Allocation<T>

      n Ts outside the GC, freed when the using block holding it ends (spec 1.4.2). Copies share the block; use it only inside that block.
