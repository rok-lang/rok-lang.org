      rok::bare::ffi

      rok::bare::ffi - NUL-terminated C strings (stdlib 1.7.2); wit is what the WIT bindings run on (1.8).

      CStr and CString keep their bytes, NUL included, in one str object, so as_ptr holds as str::as_ptr does (2.15.2). CStr::from_ptr copies.

      Modules

      • wit rok::bare::ffi::wit - what the generated WIT bindings run on (stdlib 1.8): linear-memory access at canonical ABI addresses (`i32`), the blocks strings and lists lower into, resource handles and `error-context`.
