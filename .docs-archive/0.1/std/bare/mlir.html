      rok::bare::mlir

      rok::bare::mlir - one MLIR op written in rok (stdlib spec 1.9).

      One result; region bodies are straight-line ops (one block each).

      Structs

      __mlir_type

      pub struct __mlir_type<T>

      __mlir_type<"text">: an opaque MLIR type written verbatim (index, !llvm.ptr, vector<4xi32>), as __mlir_op's R, an operand's type or a region parameter. Its values stay SSA: they are passed, bound and returned, not stored in aggregates.

      Functions

      __mlir_op

      pub unsafe fn __mlir_op<R>() -> R

      __mlir_op::<"dialect.op", R>(a, b, attributes = { "name": __mlir_attr::<"text"> }, regions = [|x: X| { ..; __mlir_op::<"scf.yield", ()>(v); }]): the op in MLIR's generic form with result type R ((): no result), written verbatim into the MLIR text. Each closure of regions is one region: its parameters are the entry block's arguments, its body ends with the terminator op and may use the enclosing values. Only in an unsafe block.

      __mlir_attr

      pub unsafe fn __mlir_attr<A>() -> A

      __mlir_attr::<"text">: an MLIR attribute as MLIR text, inside __mlir_op's attributes only.
