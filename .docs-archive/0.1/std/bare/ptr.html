      rok::bare::ptr

      rok::bare::ptr - raw pointers (stdlib spec 1.1). A pointer is its address; reading / writing through it is unsafe (refs-lang 4.15.2).

      Provenance is not tracked at run time: expose_provenance / from_exposed_provenance are the address itself, and the latter is unsafe (it makes a pointer out of a plain integer). Ptr / ConstPtr / ManyPtr are never null: #[niche(0)] makes Ptr<T> | none one address, null = none (spec 2.7.2).

        The address (provenance is lost).

      • pub const fn map_addr(self, f: fn(usize) -> usize) -> Ptr<T>

        count elements further (count * size_of::<T>() bytes).

      • pub const fn add(self, count: usize) -> Ptr<T>
      • pub const fn sub(self, count: usize) -> Ptr<T>
      • pub fn byte_offset(self, count: isize) -> Ptr<T>

        count bytes further.

      • pub const fn distance(self, origin: Ptr<T>) -> isize

        self.addr() - origin.addr() in elements.

      • pub const fn is_aligned(self) -> bool
      • pub const fn align_offset(self, align: usize) -> usize

        Elements to add so the address is a multiple of align, or usize::MAX when no element count gets there.

      • pub const fn cast<U>(self) -> Ptr<U>

        The same address as a pointer to U (alignment is the caller's).

      • pub const fn as_const(self) -> ConstPtr<T>
      • pub const fn as_many(self) -> ManyPtr<T>
      • pub unsafe fn read(self) -> T

        The T it points at. UB unless it points at a live, initialized T.

      • pub unsafe fn write(self, value: T)

        Store value where it points. UB unless that is writable T memory.

      • pub unsafe fn read_volatile(self) -> T
      • pub unsafe fn write_volatile(self, value: T)

      • pub fn offset(self, count: isize) -> ManyPtr<T>

        The first element as a single-element pointer.

      • pub fn as_const(self) -> ConstPtr<T>

      expose_provenance

      addr_of

      pub fn addr_of<T>(place: T) -> Ptr<T>

      A pointer to place itself (a local, or a field / array element of one), valid while that local is in scope: the local lives in memory and, holding GC references, stays a GC root (whose referents never move) until its scope ends.

      many_addr_of

      addr_of as the start of a run of Ts (many_addr_of(buf[0])).
