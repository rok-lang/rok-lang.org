      rok::bare::mem

      rok::bare::mem - raw memory operations, Pod and bit casts (stdlib spec 1.2.5 / 1.2.6 / 1.3).

      A bit cast goes through a scratch block outside the GC (a generic value has no address of its own): the value is stored there as A and loaded as B, with nothing in between that could collect. reinterpret checks the sizes when called (the spec's where sizeof::<A>() == sizeof::<B>() has no compile-time form yet).

      MaybeUninit

      pub struct MaybeUninit<T>

      A T that may not be initialized yet (spec 1.3.2): same size and alignment as T, and as_mut_ptr points at the variable itself. Its bits start zeroed (uninit is zeroed: a GC reference in it is null until written, never garbage).

      Traits

      Pod

      pub trait Pod

      Plain old data: every bit pattern of the type is a valid value, its layout is fixed and it has no Drop (spec 1.3.3). User structs opt in with #[derive(Pod)] (#[repr(C)] / #[repr(transparent)]).
