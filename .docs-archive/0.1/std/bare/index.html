      rok::bare

      rok::bare - raw pointers, transmute, raw allocation, pinning and volatile access, over the runtime's extern "rok" symbols only. Never in the prelude: code that needs it says use rok::bare::...

      Modules

      • alloc rok::bare::alloc - raw allocation outside the GC (stdlib spec 1.4).
      • ffi rok::bare::ffi - NUL-terminated C strings (stdlib 1.7.2); `wit` is what the WIT bindings run on (1.8).
      • gc rok::bare::gc - keeping GC objects in place for raw pointers (stdlib spec 1.6).
      • mem rok::bare::mem - raw memory operations, `Pod` and bit casts (stdlib spec 1.2.5 / 1.2.6 / 1.3).
      • mlir rok::bare::mlir - one MLIR op written in rok (stdlib spec 1.9).
      • ptr rok::bare::ptr - raw pointers (stdlib spec 1.1).
      • volatile rok::bare::volatile - accesses the optimizer keeps exactly as written (stdlib spec 1.5): MMIO, signal flags, DMA buffers.
