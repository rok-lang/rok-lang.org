      rok::std::rokon

      rok::std::rokon - ROKON (Rok Object Notation, .rokon): one value written in rok literal syntax (stdlib spec 3.9).

      parse reads a document into a Value, Value::to_string writes the canonical form, and ToRokon / FromRokon (with #[derive(Rokon)]) map rok types to and from Value. The reader is a small lexer plus a recursive descent over the literal subset (the compiler's parser is not reachable at run time).

      Decode errors carry a path (.limits["cpu"], .tags[1]); from_str turns it into line:col by re-reading the document and stopping at that path, so the happy path keeps no positions.

      Modules

      • read rok::std::rokon::read - lexer and recursive-descent reader for the ROKON subset of rok literal syntax (spec 3.9.1).
      • write rok::std::rokon::write - the canonical text of a `Value` (spec 3.9.4).

      Enums

      Value

      pub enum Value

      A ROKON value. { k: v } with identifier keys is a Struct without a name; { "k": v } (any value keys) and {} are a Dict. A path with :: is a Variant (E::V, E::V(a, k: b), E::V { f: v }); Name(a, b) (a tuple struct) is a Variant with a one-segment path.
