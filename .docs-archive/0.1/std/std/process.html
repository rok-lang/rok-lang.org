      rok::std::process

      rok::std::process (stdlib 307): child processes.

      Spawning is posix_spawnp; the program is looked up in this process's PATH (not the child's env) unless it contains /. Every fd the library opens is close-on-exec, and an exec failure comes back as the IoError. On Linux each child also has a pidfd, so a signal never hits a recycled pid.

      Windows: CreateProcessW with arguments quoted for the MSVC CRT (.exe added when there is no extension); the child inherits only its standard handles; batch files refuse arguments holding ", % or a line break. kill / signal use TerminateProcess; signal routes console events: Ctrl-C (2), Ctrl-Break (21), close (1).

      output() drains stdout and stderr together.

      signal(sig, f): the C handler writes the signal number to a pipe and a dispatcher thread (rok-signal) calls f, never in signal context. A burst that fills the pipe drops signals.
