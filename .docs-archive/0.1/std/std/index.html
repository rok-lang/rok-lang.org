      rok::std

      rok::std tier - target-dependent. Owns: fs, net, time, thread (OS), io (stdin/out/err), env, process, path, crypto (the OS random source), rokon (the ROKON data format), wit (the component model's async ABI under WIT bindings). Modules are pub(shy) so glob imports do not pull them in implicitly.

      Modules

      • crypto rok::std::crypto - the OS random source.
      • env rok::std::env (stdlib spec 306): arguments, environment variables, directories, exit.
      • fs rok::std::fs (stdlib 301): files and directories over the `openat` family, so a `Dir` handle is a capability.
      • io rok::std::io (stdlib spec 305): `IoError`, the `Reader` / `Writer` / `Seek` traits, `AsBytes` and the standard streams.
      • net rok::std::net (stdlib 302): TCP / UDP / Unix sockets, addresses, DNS.
      • path rok::std::path (stdlib spec 308): `Path`, a UTF-8 path value with Python-style `/` joining.
      • process rok::std::process (stdlib 307): child processes.
      • rokon rok::std::rokon - ROKON (Rok Object Notation, `.rokon`): one value written in rok literal syntax (stdlib spec 3.9).
      • thread rok::std::thread: OS threads, 1:1 (stdlib 304, refs-lang 7.6.6).
      • time rok::std::time (stdlib spec 303): `Duration` / `Instant` live in `rok::core::task::time` (2.18.6) and are re-exported here; the wall clock (`SystemTime`) and the boot clock (`BootTime`) are std-only.
      • wit rok::std::wit - the component model's async ABI (WASI preview 3) for the bindings `ffi::wit::import` / `ffi::wit::export` generate (stdlib spec 1.8): it runs on the executor, so it lives above `rok::bare::ffi::wit` (stdlib 0.1.2).
