      rok::std::fs

      rok::std::fs (stdlib 301): files and directories over the openat family, so a Dir handle is a capability.

      Dir::root() resolves relative paths against the working directory; a Dir opened from it refuses absolute paths and ...

      copy reflinks where the OS can (clonefileat, CopyFileExW, copy_file_range), else copies bytes. Windows: a Dir is a directory handle and permissions are the read-only attribute.

      *_async: kqueue / epoll cannot wait on regular files, so each call runs its sync twin on the blocking lane (task::spawn_blocking). A cancelled task leaves the call to finish in the background (a read_async still fills its buffer). Dir::read_dir_async streams entries in batches; the free read_dir_async lists them all at once.

      Walk

      pub struct Walk

      Recursive walk, depth first, the root first and each directory's entries sorted by name (Go filepath.WalkDir). Symlinks are listed, not followed. Each directory is read whole when reached, so a Walk never holds a stream open (stopping early leaks nothing). An unreadable directory yields its error and the walk goes on.
