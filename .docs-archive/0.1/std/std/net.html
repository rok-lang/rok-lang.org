      rok::std::net

      rok::std::net (stdlib 302): TCP / UDP / Unix sockets, addresses, DNS.

      Sockets are non-blocking underneath. Blocking calls wait in poll, so set_*_timeout bounds that wait (async uses task::timeout), and set_nonblocking(true) makes them throw WouldBlock. *_async calls suspend until the I/O driver sees the fd ready (refs-lang 7.7).

      Spec 302 lets the plain calls suspend inside a task; here they block the worker, because a sync fn cannot suspend a stackless coroutine.

      read(buf) fills buf[0..n] of a pre-sized List<u8>; writes take any AsBytes. A Unix listener's accept gives the peer's bound path (none: unnamed). sendfile / splice are Linux only; no IPv6 multicast or MSG_ZEROCOPY (302.7). TLS 1.3 is tls (302.5).

      Modules

      • tls rok::std::net::tls - TLS 1.3 (stdlib spec 3.2.5), implemented here in rok on `rok::core::crypto`: no OS or external TLS library.

      TcpStream

      pub struct TcpStream

      A TCP connection. Copies share the socket; close() (or leaving a using block) closes it for all.

      • pub fn connect(addr: SocketAddr) throws (IoError) -> TcpStream

        Connect, blocking until the handshake is done.

      • pub fn connect_timeout(addr: SocketAddr, dur: Duration) throws (IoError) -> TcpStream
      • pub async fn connect_async(addr: SocketAddr) throws (IoError) -> TcpStream

        connect that suspends the task during the handshake.

      • pub const fn fd(self) -> i32

        The OS socket descriptor (-1 once closed).

      • pub fn read(self, buf: List<u8>) throws (IoError) -> usize

        Read up to buf.len() bytes into buf[0..n]; 0 at end of stream.

      • pub async fn read_async(self, buf: List<u8>) throws (IoError) -> usize

        read that suspends the task until data arrives.

      • pub fn read_to_end(self) throws (IoError) -> List<u8>

        Everything until the peer closes its side.

      • pub async fn read_to_end_async(self) throws (IoError) -> List<u8>
      • pub fn write<B: AsBytes>(self, buf: B) throws (IoError) -> usize

        Write some prefix of buf; its length.

      • pub async fn write_async<B: AsBytes>(self, buf: B) throws (IoError) -> usize
      • pub fn write_all<B: AsBytes>(self, buf: B) throws (IoError)
      • pub async fn write_all_async<B: AsBytes>(self, buf: B) throws (IoError)
      • pub fn write_str(self, s: str) throws (IoError)
      • pub async fn write_str_async(self, s: str) throws (IoError)
      • pub const fn flush(self) throws (IoError)

        Nothing to flush: writes go straight to the socket.

      • pub fn peer_addr(self) throws (IoError) -> SocketAddr
      • pub fn local_addr(self) throws (IoError) -> SocketAddr
      • pub fn shutdown(self, how: Shutdown) throws (IoError)
      • pub fn set_nodelay(self, nodelay: bool) throws (IoError)
      • pub fn set_keepalive(self, alive: Duration | none) throws (IoError)

        Keepalive probes after alive idle (whole seconds); none = off.

      • pub const fn set_read_timeout(self, dur: Duration | none) throws (IoError)
      • pub const fn set_write_timeout(self, dur: Duration | none) throws (IoError)
      • pub const fn read_timeout(self) -> Duration | none
      • pub const fn write_timeout(self) -> Duration | none
      • pub const fn set_nonblocking(self, nb: bool) throws (IoError)

        Make the blocking calls throw WouldBlock instead of waiting.

      • pub fn try_clone(self) throws (IoError) -> TcpStream
      • pub fn close(self)

        Close now; later calls fail with InvalidInput.

      • pub fn sendfile(self, ref file: File, offset: u64, count: u64) throws (IoError) -> u64

        file[offset..offset + count] to the socket in the kernel (sendfile(2)): the bytes sent, fewer if the file ends first.

      • pub fn splice(self, ref src: File, count: u64) throws (IoError) -> u64

        Up to count bytes from src's offset to the socket through a kernel pipe (splice(2)): the bytes moved, fewer if src ends.

      • pub fn write_zerocopy(self, buf: List<u8>) throws (IoError) -> usize

        Some prefix of buf sent with MSG_ZEROCOPY (Linux 4.14+): the kernel reads buf in place; returns once it no longer needs it.

      TcpListener

      pub struct TcpListener

      A listening TCP socket.

      • pub fn bind(addr: SocketAddr) throws (IoError) -> TcpListener

        Bind and listen (SO_REUSEADDR, backlog 128). Port 0 picks one: see local_addr.

      • pub fn inherited() -> List<TcpListener>

        The listening sockets the host handed this program, in order: WASI's pre-opened sockets (wasmtime -S tcplisten=ADDR, preview 1: wasm32-wasi-threads), systemd socket activation (LISTEN_FDS) on Unix; none on Windows. Where a program cannot bind sockets itself, these are how it serves.

      • pub fn accept(self) throws (IoError) -> (TcpStream, SocketAddr)

        The next connection and its peer, blocking until one arrives.

      • pub async fn accept_async(self) throws (IoError) -> (TcpStream, SocketAddr)

        accept that suspends the task until a connection arrives.

      • pub fn local_addr(self) throws (IoError) -> SocketAddr
      • pub fn try_clone(self) throws (IoError) -> TcpListener
      • pub const fn set_nonblocking(self, nb: bool) throws (IoError)
      • pub const fn incoming(self) -> Incoming

        for c in l.incoming() { let s = try c.get(); .. }: connections forever (each item is the stream or the error accept threw).

      • pub const fn fd(self) -> i32
      • pub fn close(self)
