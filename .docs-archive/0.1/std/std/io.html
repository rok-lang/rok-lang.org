      rok::std::io

      rok::std::io (stdlib spec 305): IoError, the Reader / Writer / Seek traits, AsBytes and the standard streams.

      Byte buffers are List<u8> (305): read(buf) fills buf[0..n] of a pre-sized list. Bytes cross to the runtime as GcBuf<u8> regions (buf, off, len): reads fill the caller's list in place, every other move is one bulk copy, and bytes become a str only through the UTF-8 check of str::from_utf8.

      write_fmt takes the formatted str (an f-string), not FmtArgs (f-strings desugar to str).

      Reader

      pub trait Reader
      • fn read(ref self, buf: List<u8>) throws (IoError) -> usize

        Read up to buf.len() bytes into buf[0..n]; 0 = end of stream.

      • const fn raw_fd(self) -> RawFd

        The OS descriptor copy may hand to the kernel: one with no buffer, timeout or non-blocking mode of the stream's own. -1 (the default): none.

      • fn read_exact(ref self, buf: List<u8>) throws (IoError)

        Fill all of buf, or UnexpectedEof.

      • fn read_to_end(ref self) throws (IoError) -> List<u8>

        Every remaining byte.

      • fn read_to_str(ref self) throws (IoError) -> str

        Every remaining byte as text (InvalidData if not UTF-8).

      • fn read_line(ref self) throws (IoError) -> str

        The next line, \n included; "" at the end of the stream.

      • const fn lines(ref self) -> Lines<Self>

        The remaining lines (without \n / \r\n).

      • const fn bytes(ref self) -> Bytes<Self>

        The remaining bytes one at a time (wrap in BufReader first: each item is one read).
