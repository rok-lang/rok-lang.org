      rok::std::path

      rok::std::path (stdlib spec 308): Path, a UTF-8 path value with Python-style / joining. Separators follow the target: / on Unix; \ or / on Windows, where a path may start with a prefix (C:, \\server\share, \\?\.., \\.\..), is absolute only with a prefix and a root, and join writes \.

      Path is immutable: / returns a new one, p /= q is p = p / q. RawPath holds the OS form (Unix bytes, Windows UTF-16); the fs layer never produces one - it reports non-UTF-8 names as InvalidData.
