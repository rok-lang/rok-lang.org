      rok::std::thread

      rok::std::thread: OS threads, 1:1 (stdlib 304, refs-lang 7.6.6). Each thread is a GC mutator; blocking calls let a collection run without it.

      A panic in any thread ends the process (exit 101), so join never sees one; JoinError is an OS join failure. A handle neither joined nor detached keeps its OS thread record (there is no implicit drop).

      THREADS maps a thread id to its Rec (name, park token, thread-local values): made before a spawned thread starts and dropped when its closure returns, or on another thread's first current() / park / thread-local use.
