      rok::std::net::tls

      rok::std::net::tls - TLS 1.3 (stdlib spec 3.2.5), implemented here in rok on rok::core::crypto: no OS or external TLS library.

      Client / Server wrap a TcpStream; after the handshake they read and write application data like the stream itself, blocking or, with the *_async methods, suspending only the task. Server certificates are validated against ClientConfig::root_certs (by default the OS trust store: the macOS keychain anchors, the Windows ROOT store, the Linux CA bundle files; none on wasm). Key exchange is X25519, or the X25519MLKEM768 hybrid when enable_pq is on. Either side signs with Ed25519, ECDSA P-256 / P-384 or RSA-PSS; the server may ask for a client certificate. Sessions resume from single-use tickets (psk_dhe_ke), optionally with 0-RTT data. A connection is used by one thread, and one operation, at a time.

      TlsErrorKind

      pub enum TlsErrorKind

      What failed.

      • Io

        The underlying stream failed or closed.

      • Certificate

        The peer's certificate is malformed or not trusted for the name.

      • Protocol

        The peer broke the protocol (or offered nothing in common).

      • PeerAlert

        The peer sent a fatal alert.
