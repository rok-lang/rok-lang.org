      rok::std::env

      rok::std::env (stdlib spec 306): arguments, environment variables, directories, exit.

      set_var has no global lock: call it before spawning threads (306.3). Names and values from the OS are bytes (Windows: its UTF-16 as WTF-8); var / vars / args hand out the UTF-8 ones as str, the *_os forms raw.
