      rok::std::wit

      rok::std::wit - the component model's async ABI (WASI preview 3) for the bindings ffi::wit::import / ffi::wit::export generate (stdlib spec 1.8): it runs on the executor, so it lives above rok::bare::ffi::wit (stdlib 0.1.2).
