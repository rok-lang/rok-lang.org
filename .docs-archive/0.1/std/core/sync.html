      rok::core::sync

      rok::core::sync - concurrency primitives (stdlib spec 2.16).

      Every type is a handle over GC buffers: copying it (into a closure, another thread) shares the one primitive. Blocking goes through the runtime's address-keyed wait queue (rok_sync_wait / rok_sync_wake, futex semantics; Atomic<i32>::wait / wake expose it); a blocked thread counts as stopped for the GC.

      Not in 2.16 but provided because the blocking APIs need them: Once, Condvar (Rust-shaped).

        Frozen

        pub struct Frozen<T>

        A value made once and only read after (2.16.4b): any thread may read it without a lock. new keeps a copy of the value's collections that nothing else reaches, and get gives each reader its own copy, so no one can change what the others read. Sync parts (a Mutex, a cache that locks itself) stay shared.

        • pub const fn new(value: T) -> Frozen<T>
        • pub fn get(self) -> T

          A copy of the value: the reader's own to change.

        Trait implementations 1
        • unsafe impl<T: Send> Sync for Frozen<T>

        Condvar

        pub struct Condvar
        • pub const fn new() -> Condvar
        • pub const fn wait_async<T>(self, guard: MutexGuard<T>) -> CondvarWait<T>

          g = await cv.wait_async(g): wait that suspends the task (not the thread), both for the notification and to lock again. Spurious wakeups as for wait. A task cancelled while it waits takes the lock back if it is free (its using guard unlocks it); if another task holds it, the guard's unlock is owed instead and does nothing (the worker never blocks).

        • pub fn wait<T>(self, guard: MutexGuard<T>) -> MutexGuard<T>

          Unlock guard's mutex, block until notified (or spuriously), lock it again. Re-check the condition in a loop.

        • pub fn notify_one(self)

          Wakes the longest-waiting blocked thread. Tasks in wait_async are all woken (a spurious wakeup for all but one): a parked task's entry may be stale, and waking only it could lose the notify.

        • pub fn notify_all(self)
