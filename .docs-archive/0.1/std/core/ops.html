      rok::core::ops

      Operator traits: the source of every operator token.

      rokc binds each token to the trait method carrying its #[infix] / #[prefix] / #[postfix]; precedence and associativity are fixed by the language (3.2.3). #[lang(...)] (6.4) binds each trait to a compiler slot.
