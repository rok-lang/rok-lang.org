      rok::core::range

      Range / RangeInclusive / RangeFrom / RangeTo / RangeToInclusive / RangeFull (stdlib 2.7.4, refs-lang 3.7).

      A range expression is a value of these types (let r = 0..5;), built by the #[literal] handlers at the end of this file. for i in a..b with the range written in the loop header keeps a direct counting loop.
