      rok::core::stream

      rok::core::stream - Stream / IntoStream / FromStream (stdlib spec 2.8).

      for await x in s polls s.poll_next(ref ctx) (after s.into_stream() when s has no poll_next) like await, until it is Ready(none).

      The adapters (2.8.5) are provided methods of Stream returning the structs below (stream::Map<S, U> is not iter::Map). throttle / buffered / buffer_unordered wrap an async yield stream built by a generic helper, the others poll their source directly.
