      rok::core::panic

      rok::core::panic - the compiler hooks panic_fn / oom_fn / unreachable_fn (stdlib spec 2.14.5): print a message to stderr and exit 101. They never return: -> ! fits any slot.

      Functions

      panic

      pub const fn panic(msg: str) -> !

      Abort with msg, reporting the first caller outside a #[track_caller] chain.

      oom

      pub const fn oom() -> !

      Out of memory (Fatal). The runtime's allocation failures end in the same rok_oom.

      unreachable

      pub const fn unreachable() -> !

      Abort: code the program believed it could never reach ran.

      assert

      pub const fn assert(cond: bool, msg: str = "")

      Abort unless cond holds.

      assert_eq

      pub const fn assert_eq<T: PartialEq + Debug>(left: T, right: T, msg: str = "")

      Abort unless left == right; the message shows both via Debug.

      assert_ne

      pub const fn assert_ne<T: PartialEq + Debug>(left: T, right: T, msg: str = "")

      Abort if left == right; the message shows both via Debug.
