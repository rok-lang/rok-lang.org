      rok::core::convert

      rok::core::convert: conversion traits (stdlib 2.11) and primitive impls (2.11.8). Four policies, each named at the call: lossless into, fallible try_into (throws TryFrom::Error, OverflowError for numbers), saturating_into, and wrapping_into (= as).

      The spec writes trait Into<T> { fn into(self) -> T; }, but a blanket impl<T, U: From<T>> Into<U> for T cannot fix U from the receiver, so each *Into trait has one generic method (T from the expected type, like parse) and one blanket impl; the conversions are the *From impls. SaturatingFrom / WrappingFrom back the last two policies. The lossless impls are also rok.cast.* intrinsics (2.11.12); their bodies are the same as.

      TryFrom

      pub trait TryFrom<U>

      A conversion that can fail (2.11.4). Error is what it throws: ConversionError unless the impl names another (the numeric impls say OverflowError).

      • type Error = ConversionError
      • fn try_from(value: U) throws (Self::Error) -> Self
