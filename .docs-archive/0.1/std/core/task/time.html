      rok::core::task::time

      rok::core::task::time - Duration / Instant (stdlib spec 2.18.6, 3.3.2). rok::std::time re-exports both.

      Duration

      pub struct Duration

      A span of time: i64 nanoseconds (about ±292 years, 3.3.1).

      • pub const fn ns(n: i64) -> Duration
      • pub const fn us(n: i64) -> Duration
      • pub const fn ms(n: i64) -> Duration
      • pub const fn sec(n: i64) -> Duration
      • pub const fn min(n: i64) -> Duration
      • pub const fn hours(n: i64) -> Duration
      • pub const fn days(n: i64) -> Duration
      • pub const ZERO: Duration = Duration { ns: 0 }
      • pub const MAX: Duration = Duration { ns: 9223372036854775807 }
      • pub const fn from_secs_f64(s: f64) -> Duration

        s seconds, truncated to whole nanoseconds (saturating at the i64 range, NaN → 0 - the as rules).

      • pub const fn as_ns(self) -> i64
      • pub const fn as_us(self) -> i64
      • pub const fn as_ms(self) -> i64
      • pub const fn as_secs(self) -> i64
      • pub const fn as_secs_f64(self) -> f64
      • pub const fn subsec_ns(self) -> u32

        The part below one second (of the magnitude for a negative span).

      • pub const fn subsec_us(self) -> u32

      • pub const fn checked_add(self, rhs: Duration) -> Duration | none

      • pub const fn checked_div(self, divisor: i64) -> Duration | none
      • pub const fn saturating_add(self, rhs: Duration) -> Duration
