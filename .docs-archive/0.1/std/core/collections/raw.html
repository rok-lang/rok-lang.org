      rok::core::collections::raw

      rok::core::collections::raw - the GC buffer the collections are built on (stdlib 2.9.12). GcBuf<T> is compiler-known: one GC reference to an object holding a run of Ts, zeroed at allocation; when T holds GC references the collector traces every element. It carries no length - its owner tracks that. The functions below are compiler intrinsics (unchecked indexing); their bodies never run. Reading, writing and allocating are unsafe, and so is b[i] on a GcBuf: nothing checks the index, and a fresh buffer's zero bytes need not be a valid T.
