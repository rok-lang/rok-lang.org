      rok::core::collections::slice

      rok::core::collections::slice: Slice<T>, a zero-copy view (stdlib 2.9.7); element i is buf[start + i * stride], and the view keeps its buffer alive.

      xs[a:b] is xs.slice(a..b) (2.3.4) and xs[a:b:k] is xs.slice(index::slice_range(a, b, k, len)).step(k), with Python's semantics (bounds clamp, xs[::-1] reverses). A view of a List sees later element writes but not a regrowth, which moves the list to a new buffer; a view of an array or StrBuf views a copy.
