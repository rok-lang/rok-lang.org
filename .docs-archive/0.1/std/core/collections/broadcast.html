      rok::core::collections::broadcast

      rok::core::collections::broadcast - the element-wise dot operators on List<T> (stdlib spec 2.6.7): List op List (same length, else a panic), List op T and T op List (the scalar applies to every element). Arithmetic / bitwise ones give List<T>, comparisons List<bool>; .&& / .|| combine List<bool>s without short-circuit. An operator on core collections in source is fused into one loop by the compiler (2.6.6); these impls serve trait bounds, method calls and fn values.
