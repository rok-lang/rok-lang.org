      rok::core::fmt

      rok::core::fmt - Formatter, Display / Debug, FormatSpec and the f-string lowering targets (stdlib 2.10, refs-lang 1.7.3).

      Every rendering writes into a Formatter: the runtime's growing text plus the spec of the value being written. HIR lowers f"..." to one such text: literal pieces and primitive holes go to the runtime directly, any other hole through Display::fmt / Debug::fmt (fstr_* below), and rok_fmt_finish hands the text over as the str without a copy.

      Formatter

      pub struct Formatter

      Where a value's text goes, with the spec it is written by (2.10.2): the runtime's growing text (rok_fmt_*) and the spec packed in two words - flags: fill (bits 0..32), align, sign, type (a byte each from bit 32), # (bit 56), 0 (bit 57); counts: width, precision (32 bits each, all ones when absent).

      • pub const fn new() -> Formatter
      • pub const fn with_capacity(cap: usize) -> Formatter

        Empty, with room for cap bytes.

      • pub const fn with_spec(spec: FormatSpec) -> Formatter

        Empty, writing values per spec.

      • pub const fn finish(self) -> str

        The text written, as a str (no copy); the formatter is spent.

      • pub const fn write_str(ref self, s: str) throws (FmtError)
      • pub const fn write_char(ref self, c: char) throws (FmtError)
      • pub const fn pad(ref self, s: str) throws (FmtError)

        s cut to precision chars and padded to width (text aligns left by default).

      • pub const fn pad_integral(ref self, is_nonnegative: bool, prefix: str, buf: str) throws (FmtError)

        An integer: the sign, prefix ("0x" ..) under #, the digits buf, padded to width - right by default; 0 and = fill between the prefix and the digits.

      • pub const fn fill(self) -> char
      • pub const fn align(self) -> Alignment | none

        none when the spec names no alignment: numbers then align right, other values left.

      • pub const fn sign(self) -> Sign | none
      • pub const fn alternate(self) -> bool
      • pub const fn pad_zero(self) -> bool
