      rok::core::par

      rok::core::par - data-parallel helpers (stdlib spec 2.19), on the process's task executor (rok::core::task): from async code on the worker it runs on, from sync code with the caller as a guest worker. Chunks are claimed from a shared counter by one job per worker.

      try_scope

      pub fn try_scope<E: Send>(f: fn(TryScope<E>) throws (E)) throws (E)

      scope whose body and tasks may throw (2.19.3: "an exception cancels the children"). The first error cancels the scope: tasks that have not started never run (a running one finishes: a sync closure has no cancellation point), try_scope waits for the rest and throws that error. Not in spec 2.19, whose scope takes a non-throwing fn(Scope).
