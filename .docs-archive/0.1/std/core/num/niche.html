      rok::core::num::niche

      rok::core::num::niche - wrappers that leave out values (stdlib spec 2.2): NonZero<T> (0), NonNan<F> (NaN), Finite<F> (NaN, ±∞), Positive<T> (negatives; refs-lang 2.7.6). Each is a #[niche(..)] newtype, so NonZero<i32> | none is 4 bytes and NonNan<f64> | none 8 (refs-lang 2.7.4). new checks; new_unchecked is unsafe: a left-out value in one reads as none once it is in a sum.
