      rok::core::num::bigfloat

      rok::core::num::bigfloat: float (stdlib 2.1.3). #[keyword("float")] routes the type name here; an unsuffixed literal in a float slot is Float::from_f64, or Float::from_literal when f64 can't hold it.

      A float has f64's 53-bit significand and an i64 exponent (2.1.3 leaves the precision open). In f64's normal range it is an f64 (e == 0) with IEEE 754 operations. A finite result outside that range is promoted to m * 2^e, 1 <= |m| < 2, rounded to nearest-even instead of becoming ±inf / 0 / subnormal, so arithmetic never overflows; only / 0 and inf / NaN operands give inf / NaN.

      Float

      pub struct Float

      m * 2^e. e == 0: m is the value (zero, normal, inf or NaN, never subnormal). e != 0: 1 <= |m| < 2 and e is outside f64's normal exponents -1022..=1023.

      • pub fn try_parse(s: str) -> Float | none

        s as a decimal (-1.5e400, .5, inf, nan), correctly rounded; none when it isn't one. Decimal exponents past ±10^6 are none: the exact conversion would need a million-digit power of ten.
