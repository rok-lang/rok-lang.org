      rok::core::num::ints

      rok::core::num::ints: the integer primitives' methods and limits (stdlib 2.1.4): bit operations, byte order, and the checked_ / wrapping_ / saturating_ / overflowing_ families that spell out what plain + - * leave to the profile (2.3).

      wrapping_add / _sub / _mul and the bit counts are intrinsics; the rest is built on them. One regular block per type.

      The limits are MIN / MAX consts rather than 2.1.4's fn min() / fn max(), which would shadow Ord::min(self, rhs).
