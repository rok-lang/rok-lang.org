# 13. 파일과 네트워크 IO

이 장에서는 프로그램 바깥 세상과 이야기하는 방법을 배웁니다. 파일과 디렉토리, 경로, 표준 입출력, 환경 변수, 자식 프로세스, 그리고 TCP / UDP 소켓까지 모두 `rok::std` 에 들어 있습니다.

IO 는 언제든 실패할 수 있으므로 거의 모든 함수가 `throws (IoError)` 입니다. [10장](10-errors.html)에서 배운 `try` / `catch` 가 여기서 계속 쓰입니다.

## 파일 읽고 쓰기

가장 간단한 방법은 `fs::write` 와 `fs::read_to_str` 입니다. 파일을 열고 닫는 일은 함수가 알아서 합니다. 예제는 `env::temp_dir()` 아래에 디렉토리를 만들어 쓰고, 끝에 지웁니다.

```rok
use rok::std::fs;
use rok::std::env;
use rok::std::io::IoError;

fn main() throws (IoError) {
    let dir = env::temp_dir() / f"rok_learn13_{env::pid()}";
    try fs::create_dir_all(dir / "notes" / "2026");

    try fs::write(dir / "hello.txt", "first line\nsecond line\n");
    let text = try fs::read_to_str(dir / "hello.txt");
    print(text);
    println(f"{text.lines().count()} lines");

    try fs::read_to_str(dir / "nope.txt") catch e {
        println(f"error kind: {e.kind():?}");
        ""
    };

    try fs::remove_dir_all(dir);
    println(f"exists after cleanup: {fs::exists(dir)}");
}
```

```output
first line
second line
2 lines
error kind: NotFound
exists after cleanup: false
```

`IoError` 는 `kind()` (`NotFound`, `PermissionDenied`, `TimedOut` …) 와 사람이 읽을 메시지를 함께 가집니다. 에러 종류로 분기할 때는 `kind()` 를 비교합니다.

경로 인자는 `str` 이든 `Path` 든 받습니다 (`AsPath` 트레잇). 그래서 `"a.txt"` 도, `dir / "a.txt"` 도 그대로 넘길 수 있습니다.

## `File` 과 `OpenOptions`

조금씩 쓰거나 줄 단위로 읽으려면 `File` 을 직접 엽니다. `using` 블록을 쓰면 블록을 떠날 때 파일이 닫힙니다. 덧붙여 쓰기처럼 여는 방식을 고르려면 `OpenOptions` 를 씁니다.

```rok
use rok::std::fs;
use rok::std::fs::{File, OpenOptions};
use rok::std::env;
use rok::std::io::{IoError, Reader};

fn main() throws (IoError) {
    let log = env::temp_dir() / f"rok_learn13_log_{env::pid()}.txt";

    using f = try File::create(log) {
        try f.write_str("start\n");
    }
    using f = try File::open_with(log, OpenOptions::new().append(true)) {
        try f.write_str("more\n");
    }
    using f = try File::open(log) {
        for line in f.lines() {
            println(f"> {try line.get()}");
        }
    }
    try fs::remove_file(log);
}
```

```output
> start
> more
```

`File::create` 는 파일을 새로 만들거나 비우고, `File::open` 은 읽기 전용으로 엽니다. `lines()` 는 `Reader` 트레잇의 메서드라서 `use rok::std::io::Reader` 가 필요합니다. 각 줄은 읽기 에러일 수도 있으므로 `Result` 로 오고, `try line.get()` 으로 꺼냅니다.

## 디렉토리와 `Dir` capability

`fs::walk` 는 디렉토리를 깊이 우선으로, 이름순으로 훑습니다. `fs::read_dir` 은 한 단계만 나열합니다.

`Dir` 은 조금 특별합니다. `Dir` 핸들은 **capability** 입니다. `Dir::root()` 는 보통 경로를 쓰는 기본 핸들이고, 거기서 `open_dir` 로 연 `Dir` 은 그 디렉토리 안만 다룰 수 있습니다. 절대 경로나 `..` 로 밖에 나가려 하면 거부됩니다. 신뢰할 수 없는 경로(사용자 입력, 압축 파일 안의 이름)를 다룰 때 안전망이 됩니다.

```rok
use rok::std::fs;
use rok::std::fs::Dir;
use rok::std::env;
use rok::std::io::IoError;

fn main() throws (IoError) {
    let base = env::temp_dir() / f"rok_learn13_dir_{env::pid()}";
    try fs::create_dir_all(base / "notes" / "2026");
    try fs::write(base / "notes" / "a.md", "# a");
    try fs::write(base / "notes" / "2026" / "b.md", "# b");

    for e in fs::walk(base) {
        let e = try e.get();
        let rel = try e.path().strip_prefix(base) catch _ { e.path() };
        if rel.as_str() != "" { println(f"{rel} dir={e.is_dir()}"); }
    }

    let d = try Dir::root().open_dir(base / "notes");
    println(f"inside: {d.exists("a.md")}");
    try d.open("../../escape.txt") catch e { println(f"refused: {e.kind():?}"); };
    try d.open("/etc/hosts") catch e { println(f"refused: {e.kind():?}"); };
    try d.close();

    try fs::remove_dir_all(base);
}
```

```output
notes dir=true
notes/2026 dir=true
notes/2026/b.md dir=false
notes/a.md dir=false
inside: true
refused: PermissionDenied
refused: PermissionDenied
```

이 밖에 `create_dir`, `remove_file`, `remove_dir`, `rename`, `copy`, `metadata` 가 자유 함수와 `Dir` 메서드 양쪽에 있습니다.

## 경로: `Path`

`rok::std::path::Path` 는 UTF-8 경로입니다. Python 의 `pathlib` 처럼 `/` 연산자로 이어 붙입니다. 부모나 확장자가 없을 수도 있으므로 해당 메서드는 `T | none` 을 돌려줍니다.

```rok
use rok::std::path::Path;

let p = Path::from("/home/rok/src/main.rok");
println(f"parent:    {p.parent() ?? Path::new()}");
println(f"file name: {p.file_name() ?? "-"}");
println(f"stem:      {p.file_stem() ?? "-"}");
println(f"extension: {p.extension() ?? "-"}");
println(f"absolute:  {p.is_absolute()}");

let q = Path::from("docs") / "guide" / "intro.md";
println(f"joined:    {q}");
println(f"swapped:   {q.with_extension("html")}");
println(f"normal:    {Path::from("a/./b/../c").normalize()}");
for c in q.components() { print(f"[{c.as_str()}]"); }
println("");
```

```output
parent:    /home/rok/src
file name: main.rok
stem:      main
extension: rok
absolute:  true
joined:    docs/guide/intro.md
swapped:   docs/guide/intro.html
normal:    a/c
[docs][guide][intro.md]
```

`normalize` 는 문자열만 정리하고, `canonicalize` 는 파일 시스템에 물어 심볼릭 링크까지 풉니다.

## 표준 입출력과 환경

`println` 은 편하지만, 줄바꿈 없이 쓰거나 표준 에러로 보내려면 `io::stdout()` / `io::stderr()` 를 씁니다. `io::stdin().read_line()` 은 줄 끝의 `\n` 까지 돌려주고, 입력이 끝나면 `""` 를 돌려줍니다.

```rok build
use rok::std::io;
use rok::std::io::{IoError, Reader, Writer};

fn main() throws (IoError) {
    let out = io::stdout();
    try out.write_str("Your name? ");
    try out.flush();
    let line = try io::stdin().read_line();
    if line == "" {
        println("(no input)");
    } else {
        println(f"Hello, {line.trim()}!");
    }
    try io::stderr().write_str("bye\n");
}
```

명령줄 인자와 환경 변수는 `rok::std::env` 에 있습니다. `env::args()` 의 0번은 실행 파일 경로입니다. `env::var` 는 변수가 없으면 `VarError` 를 던집니다.

```rok
use rok::std::env;

let args = env::args();
println(f"{args.len()} arg(s)");

env::set_var("ROK_GREETING", "annyeong");
println(try env::var("ROK_GREETING") catch _ { "unset" });
env::remove_var("ROK_GREETING");
println(try env::var("ROK_GREETING") catch e { f"error: {e}" });

let mine = env::vars().filter(|kv| kv.0.starts_with("ROK_GREETING")).count();
println(f"matching vars: {mine}");
println(f"temp is absolute: {env::temp_dir().is_absolute()}");
```

```output
1 arg(s)
annyeong
error: environment variable not found
matching vars: 0
temp is absolute: true
```

## 자식 프로세스

`process::Command` 로 다른 프로그램을 실행합니다. 빌더 메서드로 인자, 환경, 작업 디렉토리를 정하고 `output()` (끝날 때까지 기다리며 stdout / stderr 를 모음), `status()` (종료 상태만), `spawn()` (기다리지 않고 `Child` 를 받음) 중 하나로 실행합니다.

```rok
use rok::std::process::Command;
use rok::std::io::IoError;

fn main() throws (IoError) {
    let out = try Command::new("echo").args(["hello", "from", "echo"]).output();
    print(try str::from_utf8(out.stdout) catch _ { "" });
    println(f"success: {out.status.success()}");

    let st = try Command::new("sh").args(["-c", "exit 3"]).status();
    println(f"code: {st.code() ?? -1}");

    try Command::new("no-such-program").status() catch e {
        println(f"spawn failed: {e.kind():?}");
    };
}
```

```output
hello from echo
success: true
code: 3
spawn failed: NotFound
```

`out.stdout` 는 바이트(`List<u8>`)이므로 `str::from_utf8` 로 텍스트로 바꿉니다. 신호로 죽은 프로세스는 `code()` 가 `none` 입니다.

## TCP 와 UDP

`rok::std::net` 의 API 는 블로킹 호출이 기본입니다. 아래 예제는 한 프로그램 안에서 서버와 클라이언트를 함께 돌립니다. 포트 `0` 으로 bind 하면 OS 가 빈 포트를 골라 주고, `local_addr()` 로 실제 주소를 알아냅니다. 서버는 스레드에서 연결 하나를 받아, 받은 글을 대문자로 돌려줍니다.

```rok
use rok::std::net;
use rok::std::net::{TcpStream, Shutdown};
use rok::std::io::{IoError, Reader, Writer};
use rok::std::thread;

fn main() throws (IoError) {
    let listener = try net::tcp_listen("127.0.0.1:0");
    let addr = try listener.local_addr();

    let server = thread::spawn(|| {
        let (conn, _) = try! listener.accept();
        let msg = try! conn.read_to_str();
        try! conn.write_str(msg.to_uppercase());
        conn.close();
        msg.len()
    });

    let client = try TcpStream::connect(addr);
    try client.write_str("hello, socket");
    // Half-close: the server's read_to_str sees the end.
    try client.shutdown(Shutdown::Write);
    println(f"reply: {try client.read_to_str()}");
    client.close();
    println(f"server read {try! server.join()} bytes");
    listener.close();
}
```

```output
reply: HELLO, SOCKET
server read 13 bytes
```

UDP 는 연결 없이 데이터그램을 주고받습니다. `recv_from` 은 받은 바이트 수와 보낸 쪽 주소를 돌려줍니다.

```rok
use rok::std::net;
use rok::std::io::{IoError, byte_buf};

fn main() throws (IoError) {
    let a = try net::udp_bind("127.0.0.1:0");
    let b = try net::udp_bind("127.0.0.1:0");
    try b.send_to("ping", try a.local_addr());

    let buf = byte_buf(64);
    let (n, from) = try a.recv_from(buf);
    println(f"got {n} bytes: {try str::from_utf8(buf[0:n]) catch _ { "?" }}");
    println(f"from b: {from == (try b.local_addr())}");
}
```

```output
got 4 bytes: ping
from b: true
```

## 비동기 IO: `*_async`

[12장](12-concurrency.html) 에서 배운 task 안에서는 블로킹 호출 대신 같은 이름에 `_async` 가 붙은 버전을 `await` 합니다. 소켓은 기다리는 동안 task 만 멈추고 스레드는 다른 task 를 돌립니다. 일반 파일은 OS 가 비동기 대기를 지원하지 않아서, 호출을 별도 스레드에서 돌리고 task 는 결과를 기다립니다. 에러는 동기 버전과 똑같이 던져집니다.

```rok
use rok::std::fs;
use rok::std::net;
use rok::std::net::TcpStream;
use rok::std::env;

let path = env::temp_dir() / f"rok_learn13_async_{env::pid()}.txt";
try! await fs::write_async(path, "written in a task");
println(try! await fs::read_to_str_async(path));
try! await fs::remove_file_async(path);

let l = try! net::tcp_listen("127.0.0.1:0");
let addr = try! l.local_addr();
let server = task::spawn(async {
    let (conn, _) = try! await l.accept_async();
    let got = try! await conn.read_to_end_async();
    conn.close();
    got.len()
});
let c = try! await TcpStream::connect_async(addr);
try! await c.write_str_async("twelve bytes");
c.close();
println(f"server got {await server} bytes");
```

```output
written in a task
server got 12 bytes
```

연결이 수천 개라면 스레드 하나씩보다 task 가 훨씬 가볍습니다. 연결이 몇 개뿐인 도구라면 블로킹 API 가 더 단순합니다.

## 정리

- 파일 통째로: `fs::read_to_str` / `fs::write`. 조금씩: `File` + `using`, 여는 방식은 `OpenOptions`.
- `Dir` 은 capability 입니다. 열린 `Dir` 밖(절대 경로, `..`)은 `PermissionDenied` 로 거부됩니다.
- 경로는 `Path` 와 `/` 연산자로 만들고, 없을 수 있는 부분은 `T | none` 으로 받습니다.
- `io::stdin/stdout/stderr`, `env::args/var/temp_dir`, `process::Command` 로 바깥 환경을 다룹니다.
- TCP / UDP 는 `net::tcp_listen` / `TcpStream::connect` / `net::udp_bind`. 포트 `0` 이면 OS 가 고릅니다.
- task 안에서는 `*_async` 버전을 `await` 합니다.
