# rok 배우기

설치부터 동시성과 FFI 까지, rok 을 처음 쓰는 사람을 위한 안내서입니다. 장마다 짧은 설명과 바로 실행해 볼 수 있는 코드가 있습니다.

이 안내서의 코드 블록은 모두 사이트를 빌드할 때 실제 툴체인으로 컴파일하고 실행해서, 적어 둔 출력과 같은지 확인합니다. 그대로 복사해 `rok run file.rok` 으로 실행해 보세요.

규칙을 빠짐없이 정의한 문서는 [언어 참조](../spec/refs-lang/index.html) 와 [표준 라이브러리 사양](../spec/refs-standard-libraries/index.html) 이고, 함수와 타입 목록은 [표준 라이브러리 API](../std/index.html) 에 있습니다. 완성된 작은 프로그램은 [예제](../examples/index.html) 에 모아 두었습니다.
