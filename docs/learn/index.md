# Learn rok

A guide for newcomers to rok, from installation to concurrency and FFI. Each chapter has a short explanation and code you can run right away.

Every code block in this guide is compiled and run with the real toolchain when the site is built, and its output is checked against the one shown. Copy any of them and run it with `rok run file.rok`.

The complete rules are defined in the [language reference](../spec/refs-lang/index.html) and the [standard library specification](../spec/refs-standard-libraries/index.html); functions and types are listed in the [standard library API](../std/index.html). Small complete programs are collected in [Examples](../examples/index.html). For quick answers to everyday tasks (reading a file, timing, threads, JSON, HTTP), see [How Do I…](20-cookbook.html).
